About this generator

Passwords for Rock N' Roll Racing (1993, Silicon & Synapse, now Blizzard). The Super Nintendo and Genesis versions use the same password algorithm, so one password works on both. Each password holds the difficulty, racer, planet, division, money, car, color, the four upgrade levels and the three weapon charge counts. The algorithm was taken from the game's own code.

If a password won't work:

  • Choose PASSWORD on the title screen, type the 12 characters, then move to END and press the button.
  • Check for mixed-up characters like 5 and S, 0 and Q, or 2 and Z. The decoder suggests fixes. There's no letter O, so an O is read as zero.

The US, European and Japanese releases all accept the same passwords. The Game Boy Advance version has no password screen: it saves to six battery-backed slots instead.

How the password is built

Each character is a 5-bit number from the alphabet BCDFGHJKLMNPQRSTVWXYZ0123456789!. The game pushes 44 bits of data into a 64-bit register, appends a 16-bit checksum (the four 16-bit words XORed together, then XORed with $6573), XORs the register with B29A 56B2 B2EB B200, and reads out 12 characters from the top. Super Nintendo code: encode $81:BF5D, decode $81:BDE9. Genesis: encode $9004, decode $8DF6.
